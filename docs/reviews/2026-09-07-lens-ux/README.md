# Roster C evidence — the UX seat pair

Empty until the seats run. Each seat writes its screenshots here under its own
subdirectory (`uxa/`, `uxb/`), PNG, committed on the seat's branch.

**Why the directory is committed before there is anything in it.** The charter
(`docs/reviews/2026-09-07-lens-ux-charter.md`) tells the seats to put evidence somewhere a
reader can open, and a path named in a charter that does not exist is exactly the dangling
citation this repo's `check:doc-citations` gate exists to refuse. The directory is the
charter's promise made openable.

Budget, per the charter: at most 40 screenshots per seat, and a seat that hits the cap says
what it dropped.

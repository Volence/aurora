## 2. How "on screen" was judged

A row that says painted means **all four**: the element has client rects; `elementFromPoint` at its
own integer centre lands on it; its rect lies inside the nearest scrolling ancestor's box on both
axes; and it lies inside the viewport. `checkVisibility()` is printed and never trusted alone.
Toasts get the same test minus the scroller (they are `position: fixed`).

Every gesture is `Input.dispatchMouseEvent` or `Input.dispatchKeyEvent`, sent only after a hit test
at the aim point says it lands on the intended element. No `.click()`, no `dispatchEvent`, no value
setter. `__dbg` is used for setup (opening the project copy) and for reads (tile hash, toast type),
never to perform the gesture under test.

## 5. The three harness defects, each a false red about the app

1. **An unawaited promise.** The recents read passed `window.api.getRecentProjects()` to
   `JSON.stringify` inside the page, which prints `{}` for any promise. R4.0 read that as "the shape
   has no list". The screen said the opposite (no recents group was listed).
2. **The badge looked for where it is not.** R3 pressed on Home, where no badge exists. It lives
   only in a level's status bar (`src/renderer/providers/map-status-classic.ts`,
   `map-status-aeon.ts`). Run 2 opens the copy and GHZ act 1 as setup and presses there.
3. **A selector for text no element owns.** `CollapsibleSection` renders its title as a bare text
   node beside the chevron span, so no element's own text is exactly `Levels`. My leaf selector
   found null, no click was sent, and "no rows" was read as the group's contents. That stopped R2's
   reopen and everything after it. The aim is now the header's title span.

Each is fixed in the harness with a comment saying what it did, and was diagnosed from that run's own
printed detail before any rerun.

## 6. Where the brief or the packets and the tree disagree

1. **F-2 says "press `Aether ◇ offline`", and the brief says "press the emulator badge"; neither says
   where.** On a cold Home there is no badge to press. It exists only while a level is open.
2. **Opening the classic copy opened an act by itself.** In classic run 1, `levelState` was already
   `ready` on GHZ act 1 before any row click. Row 1 does not depend on that: run 2's click is
   asserted, and the act it lands on is asserted.
3. **The Home tab's LEVELS cards carry no dot** after a dirty close (visible in
   `classic-r2-dirty-closed-collapsed-run2.png`). No packet promised one: the census offered the
   Explorer row *or* the Home card, and the tail packet built the Explorer. Recorded as an
   observation, not a finding.
4. **The dead socket is made by a `spawnSync` of `node -e`**, not through `spawnGuarded`. It is not
   an Electron and it has already died by SIGKILL when `spawnSync` returns, so nothing is left
   running. This is the recipe of `src/main/aether/__tests__/socket-dead-link.test.ts`.
   `check:harness-guards` is green with it (268/268 clean).

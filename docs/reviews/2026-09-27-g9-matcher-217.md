## Choice

**Any string/template literal**, substring match. It has the same zero flips as stripping comments,
and it is the only zero-flip candidate that also refuses P2 and P4.

**Rejected: literal inside a print call.** Two reasons. (i) It flips 5 real gates and the P5 control.
Making it correct needs data flow (a wrapper function, a `const` verdict), and that is a far larger
instrument than this row. (ii) Its one extra catch, P3, is the "dead FAIL branch" limit. The rule
already states that limit and does not claim to cover it. **Rejected: comments stripped.** It is
equal on the population and strictly weaker on P2 and P4. **Not taken: word boundary.** It is also 0
flips, but it is a change to which words count, and the row did not ask for it (see Left open).

## Left open

- **A literal is not a print.** G9 still passes a `'FAIL'` that is never printed, and a dead FAIL
  branch (plant P3; template control (b) above). Closing this means following the value through
  wrappers and `const` verdicts, which is data flow. The one cheap approximation, a print-call
  literal, costs 5 false alarms in 198 files.
- **Substring, not word.** `FAILED`, `FAILING`, `BYPASS` and `COMPASS` all count. A `\b` match is 0
  flips today, but it is a separate decision about which words count as a verdict.
- The G9 header's "Measured 2026-09-04: 141 registered" is a dated historical figure, left as it is.
  Today's figure (198) is in the rule's block.
